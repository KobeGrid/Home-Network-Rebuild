Home Network Wiring Audit & Rebuild
Overview

My house has Ethernet and coax runs installed by a previous ISP/contractor with no documentation — no wiring map, no consistent labeling, and at least one termination that required moving stored boxes just to find it. Before buying new networking equipment, I'm auditing every existing run in the house: tracing it, testing it, and labeling it, so any new build (switches, access points, rack placement) is based on what's actually there instead of guesswork.

This repo documents that process — the audit, what I found, the topology options I'm weighing for the rebuild, and (once decided) the actual implementation.
